## 🇬🇧 English

> **What if a *spider* — the web-crawler kind — actually went crawling?**
>
> It would crawl the article **🕷️ Spider**. That is the whole joke, and the whole program.

A **single-page, zero-dependency** web toy. An electronic spider walks across a Wikipedia article,
firing a **ray** out of a dot inside its rectangular body. When the ray lands on a **keyword**, that
word lights up — a colour shift, a highlight block, a shove, a glow — **a different CSS effect for every kind of hit**.

<br>

### ✨ Features

<table>
<tr><td>🕷️</td><td><b>Procedural spider</b></td><td>rectangular body, a dot inside it, <b>8 legs × 3 segments</b>, a joint dot per segment, legs are allowed to overlap</td></tr>
<tr><td>🔦</td><td><b>Ray from the dot</b></td><td>the beam leaves the dot <i>inside the body</i> — not from the front of the spider</td></tr>
<tr><td>🎯</td><td><b>Real hits</b></td><td>the ray <b>actually lands on</b> the word it marks: pick the word → take its bounding box → draw the beam to it</td></tr>
<tr><td>🎨</td><td><b>Many effects</b></td><td>colour change · highlight block · underline sweep · glow outline · scale pop · wave displacement</td></tr>
<tr><td>📜</td><td><b>Wikipedia as the world</b></td><td>the article text <i>is</i> the ground the spider walks on — references included</td></tr>
<tr><td>🎥</td><td><b>Cinematic travel</b></td><td>the spider stays centred while the text streams past: a camera that follows upward</td></tr>
<tr><td>⏱️</td><td><b>Deterministic</b></td><td><code>?t=&lt;seconds&gt;</code> renders an exact frame — two runs are identical</td></tr>
<tr><td>🧪</td><td><b>Self-testing</b></td><td><code>?selftest=1</code> prints an assertion report into the page title</td></tr>
<tr><td>🪶</td><td><b>Zero dependencies</b></td><td>no CDN, no framework, no build step, no images — one file</td></tr>
</table>

<br>

> [!TIP]
> **💡 Just open it.** There is nothing to install, nothing to compile, nothing to configure.


### 🕹️ Controls

| Control | | What it does |
|:--|:--|:--|
| 🔴 **Pause** | 暂停 | freeze the crawl |
| ⬆️ **Crawl up** | 向上爬行 | the spider climbs the article; the camera follows |
| ⚡ **Speed** | 速度 | how fast the text streams past |
| 📟 **Status bar** | 状态栏 | how many keywords have been marked so far — e.g. `已标注 31 捕鸟蛛饲养指南 @ 7.92s` |

### 🧠 How it works

```
        ┌────────────┐             1. the article is one long vertical strip
        │     ●──────┼─────▶ 🎯    2. the ray leaves the dot INSIDE the body
        └────────────┘             3. it lands on a chosen keyword
         ╱  │  │  ╲                4. that word gets a CSS class → an effect plays
        ●   ●  ●   ●               5. the beam retracts · 6. the next beam fires
                                    ⑦ ONE beam at a time — always
```

1. The article is laid out as a long vertical strip.
2. The spider is pinned near the middle of the viewport; the strip scrolls downward beneath it.
3. A ray is fired **towards a chosen keyword** — the word is picked first, then the beam is drawn
   from the dot to its bounding box. The two are the same event, not two separate guesses.
4. On impact the word receives one of several CSS classes, each with its own `@keyframes`.
5. The beam retracts, the effect plays out, then the next beam is fired — **never two at once**.

> [!NOTE]
> **🧩 The pun, spelled out:** a *spider* is what we call a web crawler. This one crawls the
> *Spider* article, marking keywords as it goes — the drawing is literally what a crawler does.

## 🇨🇳 简体中文

> **如果一只 *蜘蛛*（爬虫那种）真的去爬，会爬什么？**
>
> 它会去爬 **🕷️《蜘蛛》** 这个词条。这就是整个笑话，也是整个程序。

一个 **单文件、零依赖** 的网页玩具。电子蜘蛛在一篇维基百科条目上爬行，
从 **长方形身体里的那个圆点** 射出 **射线**；射线打到 **关键字**，
那个词就亮起来 —— 变色、色块、抖动、发光 —— **每一种命中对应一种不同的 CSS 特效**。

> [!TIP]
> **💡 双击打开就能玩。** 不用装东西、不用编译、不用配置。

### ✨ 特性

| | | |
|:--|:--|:--|
| 🕷️ | **程序化生成的蜘蛛** | 长方形身体 + 内部一个圆点；**8 条腿 × 每条 3 段**，每段关节处一个圆点，**腿可以交叠** |
| 🔦 | **射线从圆点发出** | 光束从**身体里的圆点**射出，不是从身体前方 |
| 🎯 | **真的打中** | **先选词 → 取该词的包围盒 → 再画出射线**，端点确实落在那个词上 |
| 🎨 | **多种特效** | 变色 · 高亮色块 · 下划线滑出 · 发光描边 · 放大弹出 · 波浪位移 |
| 📜 | **维基百科即世界** | 词条正文（含参考文献）就是蜘蛛爬行的地面 |
| 🎥 | **镜头跟随** | 蜘蛛始终在画面中央，文字向下流过它 —— 等效于镜头向上给 |
| ⏱️ | **确定性** | `?t=<秒>` 渲染精确到某一时刻；连开两次结果一字不差 |
| 🧪 | **自带自测** | `?selftest=1` 把断言结果写进页面标题 |
| 🪶 | **零依赖** | 无 CDN、无框架、无构建步骤、无图片 |

### 🚀 快速开始

```bash
git clone https://github.com/mobile-creator/spider_spider.git
cd spider_spider            # 然后直接打开 index.html
```

### 🕹️ 操作

| 控件 | 作用 |
|:--|:--|
| 🔴 **暂停** | 冻结爬行 |
| ⬆️ **向上爬行** | 蜘蛛向上爬，镜头跟着给 |
| ⚡ **速度** | 文字流过的快慢 |
| 📟 **状态栏** | 已标注了多少个关键字，例如 `已标注 31 捕鸟蛛饲养指南 @ 7.92s` |

> [!NOTE]
> **🧩 把双关说明白：** 我们把网络爬虫叫做 *spider*。这只 spider 在爬 *《蜘蛛》* 词条，
> 一边爬一边标注关键字 —— 这幅画画的，恰恰就是爬虫在做的事。

## 🇩🇪 Deutsch

> **Was, wenn eine *Spinne* — die Sorte, die das Web durchsucht — wirklich loskriechen würde?**
>
> Sie würde den Artikel **🕷️ Spinne** durchkriechen. Das ist der ganze Witz und das ganze Programm.

Ein **Ein-Datei-Spielzeug ohne Abhängigkeiten**. Eine elektronische Spinne läuft über einen
Wikipedia-Artikel und feuert einen **Strahl** aus einem Punkt in ihrem rechteckigen Körper ab.
Trifft der Strahl ein **Schlüsselwort**, leuchtet das Wort auf — Farbe, Markierung, Ruck, Glühen —
**für jede Trefferart ein anderer CSS-Effekt**.

> [!TIP]
> **💡 Einfach öffnen.** Keine Installation, kein Build, keine Konfiguration.

| | |
|:--|:--|

| 🔦 | **Strahl aus dem Punkt** — er verlässt den Punkt *im* Körper |
| 🎯 | **Echte Treffer** — Wort wählen → Box nehmen → Strahl ziehen |
